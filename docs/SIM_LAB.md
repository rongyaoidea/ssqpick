# 模拟实验室

一句话：**不预测下一期，只把“如果一直这样买”的分布、回撤和预算耗尽概率摊开。**

入口：数据页 → 模拟实验室。

## 能测什么

| 维度 | 选项 |
|---|---|
| 开奖序列 | 理论随机；历史重放（从本地开奖库有放回抽取） |
| 买法 | 每期机选单式；我的号码（选号页当前草稿，支持复式/胆拖） |
| 周期 | 156 / 780 / 1560 期（约 1 / 5 / 10 年） |
| 重复路径 | 200 / 1000 / 5000 |
| 预算 | 不设上限，或 2 千 / 1 万 / 5 万 |
| 种子 | 默认固定；同一 seed 必得同一结果 |

历史重放使用公告里的浮动奖实付额；缺失时一二等奖按 500 万 / 15 万估算。
理论随机的一二等奖直接按这两个估算值计。

## 结果口径

- **ROI 分位**：P5 / P25 / P50 / P75 / P95，单位是“奖金 ÷ 投入”。
- **盈利路径占比**：最终净收益 > 0 的路径比例。
- **最大回撤**：单条路径累计净收益从峰值回落的最大金额，以及它占该路径实际投入的比例。
- **破产路径**：预算不足以支付下一期成本而提前停止的路径占比；同时给中位可买期数。
- **最长不中**：连续没有拿到任何奖级的期数（中位 / 最坏）。
- **奖级命中 vs 理论**：按“注·期 × 单注理论概率”算期望；样本不足时
  命中 0 不能解释成概率为 0。
- **fan chart**：每个采样点的累计净收益 P5–P95 / P25–P75 / 中位线，虚线为零（回本）线。

## 实现

```
core:model
  rules/TicketMasks.kt     票面位掩码：红球池 / 胆码 / 蓝球池 / 蓝胆
  rules/TicketRules.kt     新增掩码入口 accumulateTierCounts（复用同一套奖级公式）
  rules/sim/Simulation.kt  SimSpec / SimSource / SimStrategy / simulate / SimOdds
feature:data
  SimLabViewModel.kt       实验参数、开奖库、后台计算、进度/取消
  SimLabScreen.kt          全屏实验室：设置 + 结果 + fan chart + 奖级对照
```

- `simulate` 是纯函数，使用 `kotlin.random.Random(seed)`，可复现；不依赖 Android。
- 单式走位运算；复式/胆拖用 `accumulateTierCounts` 复用一个 `LongArray`，不逐期建 Map。
- 结果只保留分位、fan chart 采样点和奖级统计，不保存全部路径；当前结果在进程内保留，
  重开 App 后需按同一 seed 重跑（seed 会显示在结果卡上）。

## 规模上限

| 买法 | 单次实验最多开奖判定数 |
|---|---|
| 每期机选单式 | 5,000,000 |
| 固定复式 / 胆拖 | 500,000 |

超出时 UI 禁用“开始模拟”并提示降档。计算在 `Dispatchers.Default` 上跑，可取消。

## 非目标

- 不预测下一期，不做“幸运号”“策略评分”。
- 不暗示“守号/机选/排除历史中奖”能提高单注中奖概率。
- 不接真实资金，不鼓励追加投注。
